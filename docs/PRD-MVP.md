# PRD - MVP 产品需求文档

## 产品目标

打造一个开放的交互式 3D 香烟包装真伪鉴别工具，让普通用户可以对照 3D 模型比对关键防伪细节，辅助判断香烟真伪。

## MVP 范围

**必须实现：**
- [ ] 单盒六面体 3D 模型展示（中华硬）
- [ ] 六个面独立纹理贴图
- [ ] 拖拽旋转查看任意面
- [ ] 点击盒子自动聚焦放大
- [ ] 防伪标注热点点击 → 弹出鉴别说明
- [ ] 占位纹理可运行，真实照片可替换
- [ ] 响应式，支持移动端触控

**不实现（放到后续迭代）：**
- [ ] 一条烟展开成 10 盒
- [ ] 单盒开盖 → 展示内部烟支
- [ ] 多品牌切换
- [ ] 搜索筛选

## 用户流程

```
用户进入页面 → 看到中华硬盒 3D 模型 ↘
拖拽鼠标/手指 → 旋转查看各个面 ↘
点击标注热点 → 弹出浮层看鉴别说明 ↘
双击/点击空白 → 回到初始视角
```

## 功能需求明细

### 1. 3D 渲染
- 产品摄影级光影，还原包装质感
- 支持 PBR 材质（粗糙度/金属度）
- 后期处理：景深、bloom、色差、晕影、胶片颗粒

### 2. 交互
- 左键拖拽旋转，滚轮缩放
- 移动端双指缩放、单指旋转
- 双击盒子 → 复位视角
- 点击标注热点 → 高亮 + 弹窗

### 3. 防伪标注
- 每个标注一个 3D 坐标位置
- 热点可视化（半透明小球/方框）
- 点击弹出标题 + 鉴别说明浮层

## 非功能需求

- 首屏加载 ≤ 2MB（纹理压缩后）
- 60fps 渲染在现代手机上
- 数据驱动，方便扩展新品牌
- 公开可访问，部署在 GitHub Pages

## 验收标准

1. 打开页面能看到中华硬盒 3D 模型
2. 能旋转查看六个面
3. 能点击三个防伪标注点看说明
4. 手机端触控正常
5. GitHub Pages 可正常访问
