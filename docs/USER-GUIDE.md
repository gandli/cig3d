# 用户使用指南

## 这是什么？

cig3d 是一个开放式 3D 香烟包装真伪鉴别工具。你可以在浏览器里旋转 3D 模型，对照关键防伪点学习如何鉴别真伪。

## 如何使用

### 基本操作

- **拖拽**：鼠标/手指拖拽旋转烟盒，查看各个面
- **滚轮/双指缩放**：放大看清细节
- **双击**：复位到初始视角
- **点击标注点**：弹出浮层查看鉴别说明

### 鉴别技巧

1. 先看整体包装配色和版型，和 3D 模型比对
2. 旋转到标注点位置，对照文字说明看关键细节
3. 放大看印刷清晰度、烫金光泽，和真品特征比对

## 常见问题

**⚠️ 本工具仅供学习参考，不能 100% 代替专业鉴定。** 最终真假判断请以烟草公司/工商鉴定为准。

## 在手机上能用吗？

可以，支持触控操作：单指旋转，双指缩放。推荐横屏观看体验更好。

## 图片不加载怎么办？

- 检查网络连接
- 刷新页面重试
- 如果是贡献新品牌后不显示，检查文件名和 JSON 路径是否匹配（大小写敏感）
