# 技术设计文档

## 坐标系说明

烟盒采用中心原点坐标系：

- 单位：**分米**（dm），和厘米换算：1 dm = 10 cm
- 原点 (0, 0, 0)：盒子几何中心
- X轴：向左 → 向右，范围 `[-width/2, +width/2]`
- Y轴：向下 → 向上，范围 `[-height/2, +height/2]`
- Z轴：向后 → 向前，范围 `[-depth/2, +depth/2]`

常见烟盒尺寸示例（中华硬）：`8.8cm × 8.9cm × 2.2cm` → 转为分米：`[0.88, 0.89, 0.22]`

## 灯光设计（产品摄影级）

参考 `claude-black-3d-card` 演播室布光：

1. **主光源**：矩形软box（6盏方向光组成）模拟左侧高位柔光窗，给整个盒面均匀照明
2. **轮廓光**：右侧后方暖色窄光，勾勒烟盒边缘，增强立体感
3. **扫光**：小聚光打向盒边，增强材质高光
4. **环境光**：低强度 IBL 环境贴图，补暗部

## 后期处理

使用 `@react-three/postprocessing` 实现：

| 效果 | 参数 | 目的 |
|------|------|------|
| 景深 | 小光圈，焦点在烟盒 | 模拟大光圈摄影，突出主体 |
| Bloom | 低强度，只作用高光 | 烫金/银浮雕高光出效果 |
| 色差 | 微小偏移 | 模拟镜头色散，增加真实感 |
| 晕影 | 边缘轻微压暗 | 视觉中心聚焦烟盒 |
| 胶片颗粒 | 低强度 | 增加质感，避免过于CG |

## 交互流程

```
初始加载 → 相机在远处对准盒子 ↘
↓
用户点击盒子 ↘
↓
GSAP 平滑动画：相机推近聚焦盒子 → 缩放至合适大小 ↘
↓
用户拖拽 → 旋转盒子查看各个面 ↘
↓
用户点击标注热点 → 弹出鉴别文案浮层 ↘
↓
用户点击空白/返回按钮 → 相机退回到初始位置
```

## 数据驱动设计

- 每个品牌全配置化，核心组件不关心具体品牌数据
- 纹理按需加载，切换品牌无需重新加载页面
- 新增品牌只需要加图片和JSON，不改核心代码

## 性能考量

- 纹理压缩：JPEG 质量 80%，单张 ≤ 1MB
- 几何体复用：多个盒子共享相同 BoxGeometry
- 动态导入：多品牌场景下可按需异步加载品牌数据
