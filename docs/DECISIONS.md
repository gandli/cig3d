# 设计决策记录

记录所有重要设计决策，方便回溯。

---

## 2026-07-21：技术栈选型

**决策：** `Vite + React + React Three Fiber + Drei + GSAP + Tailwind CSS`

**备选：** 纯原生 Three.js 单文件（像 claude-black-3d-card）

**理由：**
- 用户要求「最新最流行」，React Three Fiber 是 2026 前端 3D 主流方案
- 组件化便于后续扩展（一条烟/多品牌）
- Drei 提供大量开箱即用组件，减少重复造轮子
- GSAP 做相机动画比 Three.js 内置 tween 更方便
- Tailwind CSS 快速写弹窗/UI

**结果：** 按此选型初始化。

---

## 2026-07-21：几何体来源

**决策：** MVP 用纯代码 `BoxGeometry`，不做 Blender 建模

**备选：** Blender 建圆角烟盒导 GLB

**理由：**
- MVP 先跑通纹理和交互，几何细节后续迭代
- 纯代码不需要建模软件，改尺寸方便
- 后续要开盖再换分层模型不迟

**结果：** BoxGeometry 方案。

---

## 2026-07-21：MVP 范围

**决策：** 首版只做「中华（硬）单盒六面体」，砍掉一条/10盒/开盖

**备选：** 直接做一条 → 10盒 → 单盒开盖全链路

**理由：**
- 范围收缩，快速验证交互和纹理管线
- 一步一个脚印，每个阶段可交付可测试
- 用户可以先看效果再往下做

**结果：** MVP = 单盒 + 交互 + 防伪标注。

---

## 2026-07-21：素材管线

**决策：** 本地自托管 + 数据驱动 JSON，不用第三方 CDN

**备选：** 热链 ciggies.app 图片

**理由：**
- 跨域问题，且稳定性不受控
- 版权合规性更安全
- 用户自己拍照片可以增量添加
- 完全静态，可部署在 GitHub Pages

**结果：** 占位纹理先跑通，用户后续替换真实照片。

---

## 2026-07-21：视觉风格

**决策：** 产品摄影级，做演播室灯光 + 后期处理

**备选：** 简约干净，平光无后期

**理由：**
- 真伪鉴别需要看清包装细节，光影好能突出浮雕/烫金质感
- 参考 claude-black-3d-card 成功案例，这种风格视觉表现力强
- 产品展示场景就是要摄影级效果

**结果：** 软box主光 + 轮廓光 + 扫光 + 后期五步。

---

## 2026-07-21：防伪标注内容

**决策：** 首版用常识文案做骨架，用户后续可改

**备选：** 等用户提供完整鉴别手册再开工

**理由：**
- 不阻塞开工，先把交互做出来
- 数据驱动，文案随时可替换
- 骨架有了，用户填内容很方便

**结果：** 先写常识级标注，保交互闭环。
