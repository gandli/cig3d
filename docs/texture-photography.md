# 纹理拍摄规范

为保证 3D 模型贴上去不变形，拍摄包装照片请遵循以下规范：

## 拍摄要求

1. **平面拍摄** — 烟盒放在平整桌面上，相机与拍摄面**垂直**，避免透视畸变
2. **完整覆盖** — 拍摄整个面，边缘多留 10% 余量（程序会自动对齐）
3. **光线均匀** — 避免强光反光、阴影，阴天窗边自然光最佳
4. **分辨率** — 最短边不小于 1000 像素，推荐 2000 像素（保证清晰度）
5. **格式** — JPEG，质量 80-90%，单张不超过 1MB

## 文件命名

放入对应品牌目录，文件名固定：

| 面         | 文件名     | 说明                     |
|------------|------------|--------------------------|
| 正面       | `front.jpg`| 品牌主视觉面             |
| 背面       | `back.jpg` |                          |
| 左侧       | `left.jpg` |                          |
| 右侧       | `right.jpg`|                          |
| 顶面（开盖端）| `top.jpg` |                          |
| 底面       | `bottom.jpg` |                        |

## 常见问题

### 拍出来有畸变怎么办？
- 手机拍照打开「广角校正」
- 后期用 Photoshop「镜头校正」拉直边缘

### 透明包装膜反光？
- 偏光镜（如果相机支持）
- 换角度避开光源反射
- 轻微反光不影响使用，项目本身做材质处理会弱化
