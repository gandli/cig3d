# 架构文档

## 高层架构

```
┌─────────────────────────────────────────────┐
│                   Browser                     │
├─────────────────────────────────────────────┤
│  ┌───────────┐      ┌─────────────────────┐  │
│  │  React    │  →   │  React Three Fiber  │  │
│  │  Components│     │  Three.js 渲染     │  │
│  └───────────┘      └─────────────────────┘  │
│         ↓                    ↓                 │
│  ┌─────────────────────────────────────────┐  │
│  │       JSON 品牌数据 (src/data/)           │  │
│  │       纹理图片 (public/textures/)         │  │
│  └─────────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

**完全静态，无后端**：所有数据打包在前端，部署后无需服务器。

## 组件分层

```
App.tsx
├── 状态管理：当前聚焦、当前标注
├── Scene.tsx
│   ├── 环境贴图
│   ├── 灯光系统
│   ├── 后期处理 (EffectComposer)
│   └── CigaretteBox.tsx
│       ├── BoxGeometry + 六面材质
│       ├── 纹理加载
│       └── Annotation 热点 (每个一个小球)
└── AnnotationPopup.tsx (HTML 浮层，在 Three.js 之上)
```

## 数据流

```
品牌 JSON → CigaretteBox → 加载六个纹理 → 渲染六面体
        ↓
用户点击热点 → App 更新状态 → Popup 显示文案
        ↓
用户拖拽 → OrbitControls 控制相机旋转
        ↓
用户点击盒子 → GSAP 驱动相机平滑移动到聚焦位置
```

## 关键设计决策

1. **数据驱动** — 品牌数据与渲染组件完全分离，新增品牌无需修改组件
2. **自托管资产** — 纹理存在项目里，不依赖第三方，稳定可靠
3. **渐进式细节** — MVP 先长方体，后续迭代加圆角开盖，不阻塞进度
4. **React 集成** — 使用 React Three Fiber，符合现代前端开发习惯，生态完善

## 部署架构

- 托管：GitHub Pages
- 访问：`https://gandli.github.io/cig3d/`

## 可扩展性

- 水平扩展品牌：新增 JSON + 纹理即可，不碰核心代码
- 垂直扩展功能：可以加一条烟 → 多盒 → 开盖，组件层次已预留
- 换品牌可以做品牌选择页，不影响现有结构
